Flight Roulette release notes

Current version: v1.3.0

v1.3.0 — What’s Above Me?

11 August 2026
  • New location-based What’s Above Me? mode.
  • Ask the browser for location permission and scan the live ADS-B feed around you.
  • Nearby aircraft are sorted by approximate distance from your position.
  • See callsign, aircraft type, altitude, speed and distance at a glance.
  • Capture a nearby aircraft directly into My Hangar.
  • Open any nearby aircraft on the existing live tracker.
  • Added What’s Above Me? to the burger menu.

v1.2.0 — The Hangar Update

11 August 2026
  • Save the aircraft you discover as persistent collector cards.
  • New My Hangar collection library stored in the browser.
  • Aircraft cards include callsign, type, registration, ICAO, altitude, speed, discovery location and time.
  • Rarity system: Common, Uncommon, Rare and Ultra Rare.
  • Duplicate aircraft are counted rather than silently replacing the first discovery.
  • Collection statistics and aircraft-type progress.
  • New burger menu with My Hangar and Release Notes shortcuts.
  • Current version remains clickable in the footer.

v1.1.0 — Live Tracker

11 August 2026
  • Added embedded OpenStreetMap live aircraft tracking.
  • Follow the selected ICAO transponder address using adsb.lol.
  • Moving aircraft marker, reported heading rotation and session flight trail.
  • Auto-follow and manual centre controls.
  • Altitude, speed, heading and coordinates refresh while tracking.
  • Added clickable version number and in-site release notes.

v1.0.0 — First Flight

11 August 2026
  • Introduced Spin the Skies.
  • Random discovery of real aircraft from open ADS-B feeds.
  • Displayed callsign, aircraft type, registration, altitude, speed, heading and live coordinates when available.
  • No API key required.

Storage notice

Hangar cards are stored with localStorage on this device and browser. Clearing website data or using a different device will not carry the collection across.
